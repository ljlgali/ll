# 天气查询与出行建议

## 使用场景

当用户询问某城市当前天气、未来几天天气预报、或者出门穿衣建议时，按以下步骤行动：

1. **获取当前日期和时间**：调用 getDate 工具，确认"今天"是哪一天
2. **联网搜索天气**：调用 searchWeb 工具，用"`<城市名>` 天气预报 今明后三天"作为 query
3. **整理回复**：
   - 列出今、明、后三天的温度范围
   - 天气现象（晴/多云/雨/雪）
   - 结合温度差给出穿衣建议（如"早晚温差大，建议带外套"）
   - 如果有特殊天气（暴雨/台风/高温预警），提醒注意事项

## 注意事项

- 天气数据必须来自联网搜索，**禁止编造任何具体温度数字**
- 用户未指定城市时，先询问"请问你想查询哪个城市的天气？"
- 如果 searchWeb 返回多条来源冲突，优先采纳时间最接近当前的那条

# 土壤分析与施肥 Skill

当用户询问土壤怎么样、该不该施肥、施什么肥、施多少时，调用本 Skill。

## 执行步骤

1. 先收集关键信息：作物种类 + 区域 + 土壤类型（用户说不清楚时追问）
2. 根据目标作物，估算其养分需求（N/P/K）
3. 给出推荐施肥量 + 基肥/追肥分配
4. 如果用户提供了测土数据，进一步精细调整
5. 必要时联网搜索"[作物] [区域] 施肥方案 2026"

## 主要土壤类型速查

| 土类 | 区域 | 特点 | 建议 |
|------|------|------|------|
| 黑土 | 东北平原 | 有机质丰富（4-6%），团粒结构好，肥力高 | 施氮为主，磷钾为辅；注意防治玉米螟 |
| 黄壤 | 南方丘陵 | 酸性强（pH 4.5-5.5），有机质较低 | 施石灰调酸；增施有机肥；钾肥要足 |
| 红壤 | 华中/华南 | 酸性，磷有效性低，缺硼缺钼 | 施过磷酸钙（与有机肥混匀堆腐）；补硼钼微肥 |
| 潮土 | 华北平原 | 石灰性（pH 7.5-8.5），速效钾充足，速效磷不足 | 施磷为主；氮肥分次追；注意锌肥补充 |
| 水稻土 | 长江中下游 | 长期淹水，还原性强 | 基肥深施；追肥浅水层施；钾肥后期追 |
| 沙土 | 西北/沿海 | 保水保肥差，养分低 | 多施有机肥改良；化肥少量多次；滴灌最佳 |

## 主要作物施肥参考（每亩用量，以有效成分计）

### 冬小麦（华北）
- 基肥：有机肥 2-3 方 + N 5-7kg + P2O5 8-10kg + K2O 5-8kg
- 返青肥：N 4-6kg（尿素 10-15kg）
- 拔节肥：N 5-7kg（尿素 12-15kg）
- 灌浆期：磷酸二氢钾 0.3kg 叶面喷 1-2 次

### 夏玉米（华北）
- 基肥：N 10-12kg + P2O5 5-8kg + K2O 8-10kg（麦后抢播，基肥可减）
- 拔节肥（7-8 叶）：N 8-10kg（尿素 20-25kg）
- 大喇叭口期：叶面喷磷酸二氢钾 0.3kg
- 缺锌地块：苗期喷硫酸锌 0.1% 溶液 2 次

### 水稻（早稻，华南）
- 基肥：腐熟有机肥 1-2 方 + N 6-8kg + P2O5 6-8kg + K2O 8-10kg（全部基肥）
- 分蘖肥（移栽后 7-10 天）：N 4-6kg（尿素 10-15kg）
- 穗肥（幼穗分化期）：N 3-4kg + K2O 5kg
- 破口期：叶面喷磷酸二氢钾 0.3kg + 尿素 0.5kg

### 大豆（夏播）
- 基肥：N 3-5kg + P2O5 6-8kg + K2O 8-10kg
- 开花期：如前期肥力足不追氮肥（固氮菌补充），可喷硼肥 0.2kg
- 鼓粒期：磷酸二氢钾 0.3kg + 钼酸铵 0.05kg 叶面喷

### 棉花
- 基肥：有机肥 2-3 方 + N 6-8kg + P2O5 8-10kg + K2O 10-12kg
- 蕾肥：N 3-5kg
- 花铃肥（关键！）：N 8-10kg + K2O 5-8kg
- 盖顶肥（7月底-8月初）：N 3-5kg
- 叶面喷硼肥 2-3 次，防止落蕾落铃

## 输出规范

回答用户时：
1. 先问清楚作物、区域、土壤类型（用户没说清时）
2. 给出 N/P/K 推荐量（每亩公斤数，有效成分）
3. 换算成商品肥用量（如尿素含 N 46%，所以 10kg N ≈ 22kg 尿素）
4. 分配基肥/追肥的时机和比例
5. 说明注意事项（酸性土调酸、沙土多次少量、缺锌补锌等）

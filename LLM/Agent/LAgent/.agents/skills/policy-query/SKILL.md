# 农业政策与行情查询 Skill

当用户询问农业补贴、最新政策、农产品价格走势、农资行情时调用本 Skill。

## 执行步骤

1. 明确用户想查什么：补贴 / 行情 / 政策 / 其他
2. 调用 `searchWeb` 联网检索
3. 来源优先顺序：
   - [农业农村部官网](https://www.moa.gov.cn) → 权威政策
   - [财政部官网](https://www.mof.gov.cn) → 补贴资金
   - [全国农产品商务信息公共服务平台](https://nc.mofcom.gov.cn) → 价格行情
   - [中国农业信息网](https://www.agri.cn) → 综合农情
   - 地方农业部门 → 省级/市级具体实施细则
4. 调用 `fetchWeb` 获取关键页面的完整正文
5. 用通俗语言解读，把政策条款翻译成"农户实际能拿多少"

## 输出规范

- 补贴类：说清楚 **补贴对象、标准（每亩/每台多少钱）、申请条件、发放时间**
- 行情类：引用**具体日期、具体产地/批发市场的价格数字**，不笼统说"涨跌"
- 政策类：说明**发布机构、文号、生效日期、关键条款摘要**
- 所有联网信息标注来源和链接
- 用户问的是地方具体政策时，提醒"以上为全国层面政策，具体到 XX 省/市可能有细化规定，建议咨询当地农业农村局"

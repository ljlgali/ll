# 农作物病虫害防治 Skill

当用户询问某种作物得了什么病、生了什么虫、怎么防治时，调用本 Skill。

## 核心原则

### 防治优先级
1. **农业防治**（选用抗病品种、轮作、合理密植、深翻灭茬）→ 优先推荐
2. **物理防治**（诱虫灯、粘虫板、防虫网）→ 绿色手段
3. **生物防治**（天敌释放、微生物农药）→ 减少化学依赖
4. **化学防治** → 最后选项，必须说明药剂、用量、安全间隔期

### 安全红线
- 严禁推荐国家**禁用/限用农药**（见下方名单）
- 化学农药必须标注**安全间隔期**（最后一次施药到收获的天数）
- 严格按登记作物推荐使用，不得扩大使用范围

## 禁用/限用农药名单（必须牢记）

**国家明令禁止使用的农药（任何作物、任何场合都不能推荐）：**
甲胺磷、甲基对硫磷、对硫磷、久效磷、磷胺、六六六、滴滴涕、毒杀芬、二溴氯丙烷、杀虫脒、二溴乙烷、除草醚、艾氏剂、狄氏剂、汞制剂、砷类、铅类、敌枯双、氟乙酰胺、甘氟、毒鼠强、氟乙酸钠、毒鼠硅、苯线磷、地虫硫磷、氯唑磷、甲基硫环磷、治螟磷、内吸磷、硫环磷、特丁硫磷、甲基环硫磷、涕灭威、克百威、灭多威、敌百虫（2024 年起禁用于蔬菜）。

**限用农药（部分作物禁用或有严格限制）：**
- 甲拌磷、甲基异柳磷、克线磷、水胺硫磷 → 严禁用于果树、蔬菜、茶叶、中药材
- 乐果、氧化乐果 → 限制在蔬菜上使用
- 毒死蜱、三唑磷 → 蔬菜上限制使用

## 常见病虫害防治方案

### 小麦赤霉病
| 阶段 | 措施 |
|------|------|
| 预防 | 选用抗耐病品种；开好三沟降湿；避免秸秆还田过多 |
| 早期（齐穗期）| 药剂防治：氰烯菌酯 100mL/亩 + 戊唑醇 15mL/亩，兑水 50L 喷穗部 |
| 注意 | 花期遇雨必须抢在雨停间隙抢治；安全间隔期 30 天 |

### 小麦条锈病
| 阶段 | 措施 |
|------|------|
| 监测 | 春季查发病中心，见点片发病即喷药控制 |
| 药剂 | 三唑酮（粉锈宁）15% 可湿性粉剂 80-100g/亩，间隔 7-10 天连喷 2 次 |
| 注意 | 避免单一种植同一品种，合理施肥防倒伏 |

### 水稻稻瘟病
| 阶段 | 措施 |
|------|------|
| 苗瘟 | 秧田期发现病苗即喷三环唑 75g/亩 |
| 叶瘟 | 发病初期喷富士一号（稻瘟灵）60mL/亩 或 三环唑 75g/亩 |
| 穗颈瘟 | 破口期（抽穗 5-10%）是关键时期，三环唑 + 破口前 7 天和齐穗期各喷 1 次 |
| 农业防治 | 合理施肥（氮肥不过量）；浅水灌溉，够苗晒田 |

### 水稻稻飞虱
| 阶段 | 措施 |
|------|------|
| 生物防治 | 保护自然天敌（蜘蛛、黑肩绿盲蝽）；释放褐腰赤眼蜂 |
| 化学防治 | 吡虫啉 10% 可湿性粉剂 30-40g/亩；噻虫嗪 20g/亩；呋虫胺 40g/亩 |
| 注意 | 药液要喷到植株基部；安全间隔期 21 天 |

### 玉米螟
| 阶段 | 措施 |
|------|------|
| 物理/生物 | 性诱剂诱杀成虫；释放赤眼蜂（每亩 1-2 万头） |
| 化学防治 | 心叶末期撒 Bt 颗粒剂 200g/亩 或 氯虫苯甲酰胺 10mL/亩 |
| 注意 | 防治关键期在喇叭口期（心叶末期） |

### 玉米大斑病
| 阶段 | 措施 |
|------|------|
| 农业防治 | 选用抗病品种；合理密植；增施磷钾肥；收获后深翻灭茬 |
| 化学防治 | 发病初期喷 戊唑醇 15mL/亩 + 代森锰锌 150g/亩，间隔 7-10 天连喷 2-3 次 |

### 大豆食心虫
| 阶段 | 措施 |
|------|------|
| 生物/物理 | 性诱剂诱杀；释放赤眼蜂 |
| 化学 | 成虫盛发期喷 氰戊菊酯 30mL/亩 或 溴氰菊酯 |

### 蔬菜蚜虫（通用）
| 阶段 | 措施 |
|------|------|
| 绿色防控 | 黄板诱杀；银灰色地膜驱避；保护瓢虫、草蛉等天敌 |
| 药剂 | 吡虫啉 20% 水剂 10mL/亩；啶虫脒；噻虫嗪 |
| 注意 | 安全间隔期 7-14 天（因作物而异）；菊酯类在蔬菜上有更严格限制 |

## 输出规范

回答用户时，结构建议：
1. 先判断是什么病虫害（如果用户没说清楚，先追问作物 + 时间 + 症状描述）
2. 给出农业/物理/生物防治方案（绿色优先）
3. 最后给出化学方案，**必须标注药剂名称、用量、安全间隔期**
4. 严禁推荐"全能""奇效""一扫光"等违规产品宣传语

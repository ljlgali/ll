# 农作物生产日历 Skill

当用户询问某种作物什么时候播种、什么时候施肥、什么时候收获时，调用本 Skill。

## 支持作物

小麦（冬小麦/春小麦）、水稻（早稻/中稻/晚稻）、玉米（春玉米/夏玉米）、大豆、棉花、马铃薯、花生、油菜。

## 执行步骤

1. 确认作物种类 + 用户所在区域（华北/东北/华东/华中/华南/西南/西北）
2. 确认种植制度（春播/夏播/秋播）
3. 查下方日历表给出关键时间点
4. 如果日历表信息不全，调用 `searchWeb` 补充查询"[作物] [区域] 播种期 2026"

## 日历表（中国主要区域参考）

### 冬小麦（华北平原）
| 阶段 | 时间 | 备注 |
|------|------|------|
| 播种 | 10月中-11月中 | 日均温 15-18℃ |
| 越冬 | 12月-次年2月 | 壮苗标准：冬前 6-8 叶 |
| 返青 | 3月上-3月中 | 追返青肥 10-15kg 尿素/亩 |
| 拔节 | 4月上-4月中 | 拔节期灌水 + 防纹枯病 |
| 灌浆 | 5月上-5月下 | 防蚜虫、喷叶面肥 |
| 收获 | 6月上-6月中 | 蜡熟末期抢收 |

## 注意事项

- 以上日期为常年平均，具体以当年节气和天气为准
- 气候变化、品种差异会导致时间偏移 ±10 天属正常
- 用户给出具体地理位置后，应进一步联网搜索当地农业气象站或农技站的最新建议

# 天气穿搭提示 Skill

当用户询问今天穿什么、出门带不带伞、冷不冷等问题时，调用本 Skill。

## 执行步骤

1. 调用 `getDate` 工具获取当前日期
2. 调用 `searchWeb` 搜索"[城市] 今日天气预报"，如果用户没说城市，用搜索"全国主要城市天气预报"
3. 根据搜索结果里的温度、降水、风力，给出 1-2 句穿搭建议
4. 如果用户没说城市，提醒用户指定城市以获得更准确建议

## 输出风格

- 口语化，简短
- 给出具体衣物名称（卫衣/短袖/夹克/冲锋衣等）
- 有降水时提醒带伞
